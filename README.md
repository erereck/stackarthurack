# Stack Arthur Attack

Um clone web/mobile inspirado em **Stack Attack 2 Pro** (Mobile Scope / Siemens, 2003), feito para o Arthur jogar direto no navegador.

## Controles

- **◀ / ▶**: andar e empurrar caixas lateralmente
- **▲**: pular
- No teclado: `A/D` ou setas; `W`, `↑` ou `Espaço` para pular

## Mecânicas implementadas

- Caixas derrubadas por guindastes
- Empurrar caixas, sem sistema moderno de carregar (mantém a restrição clássica)
- Sequências horizontais de 3+ caixas iguais desaparecem
- Linha horizontal completa também é limpa
- Progressão para múltiplos guindastes conforme o jogador limpa linhas
- Caixa caindo na cabeça mata
- Possibilidade de destruir/escapar de caixa com salto por baixo
- Bônus de pontos
- Capacete que absorve impacto
- Três super-pulos como power-up
- 6 personagens com comportamentos diferentes
- Recorde salvo no navegador
- Controles grandes e responsivos para touchscreen
- Layout adaptado para celular e modo paisagem baixo

## Observação de fidelidade

As referências públicas de Stack Attack 2 Pro são bastante incompletas e até se contradizem em alguns detalhes (por exemplo, descrições citam de 3 a 8 guindastes). A implementação prioriza o comportamento visível nas capturas/gameplays e as descrições contemporâneas: empurrar caixas, limpar linhas/sequências, morrer por impacto, power-ups, múltiplos guindastes e seleção de seis personagens.

O visual é propositalmente original/simplificado; o foco é reproduzir a sensação e as regras, não copiar os assets do jogo da Siemens.
